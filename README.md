# منصة زكي للسوشال ميديا

منصة ويب لإدارة كل حسابات السوشال ميديا من مكان واحد، والذكاء الاصطناعي يقود كل خطوة (كتابة، جدولة، رد، تحليل).
المواصفات الكاملة بـ `docs/SPEC_platform.docx` وبرومبتات البناء بـ `docs/BUILD_PROMPTS_GLM.docx`.

**الحالة:** الخطوة 01 (الهيكل + دوكر + فحص الصحة). الباقي بالترتيب حسب ملف البرومبتات.

## التشغيل المحلي

```bash
docker compose up --build
```

بعدها افتح <https://localhost> (شهادة محلية، المتصفح ممكن يحذّر مرة وحدة) وجرّب <https://localhost/api/health>.

## النشر

- كل دمج على `main` بيبني الصورتين على جيت هاب، وبيجرّبهم، وبينشرهم بـ `ghcr.io/iahmed30004000-wq/zaki-social-backend` و `...-frontend`، وبيبلّغ كوليفاي.
- كوليفاي بيشغّل `docker-compose.prod.yml` (صور جاهزة، بدون بناء على السيرفر).
- التفاصيل والقواعد للوكلاء بـ `AGENTS.md`.
